# 新手上手指南 · Getting Started

> 本文写给**第一次打开 Hesi 的用户**。目标：5 分钟内体验到"终端 + AI 协作"的核心价值，不再被一长串功能列表劝退。

---

## 一、先跑起来（二选一）

### 方案 A：零安装（推荐新手 / 不想装 Node）

用 **桌面托盘版**（自带便携 Node.js，离线可用）：

```text
Windows：双击 tray.bat
macOS ：在终端运行 ./tray.sh（首次需 chmod +x tray.sh）
Linux  ：在终端运行 ./tray.sh
```

启动后托盘出现 Hesi 图标，浏览器自动打开 `http://127.0.0.1:4264`。
欢迎页点「AI 智能体（一键安装）」即可离线安装 OpenCode / Codex 等 CLI Agent。

### 方案 B：从源码运行（开发者）

```bash
git clone https://github.com/qiuqiukof-oss/Hesi.git
cd Hesi
npm install
npm run build          # 构建前端（产出 public/bundle.js）
npm start              # → http://127.0.0.1:4264
```

> 浏览器控制功能可选：`npx playwright install chromium`

## 二、第一次打开，照做这 4 步

如果你不知道从哪开始，按这个顺序做一遍，就能感受到 Hesi 在干什么：

| 步骤 | 操作 | 你会看到 |
|------|------|----------|
| ✅ 1. 开终端 | 左侧/顶部点「新建终端」标签 | 一个原生终端，默认在 `C:\Users\<你>`（Windows）或 `$HOME` |
| ✅ 2. 敲一条命令 | 输入 `dir`(Win) / `ls`(Mac/Linux) 回车 | 当前目录文件列表 |
| ✅ 3. 开 AI 聊天 | 点聊天图标，打开聊天面板 | 一个可对话的 AI 助手 |
| ✅ 4. 问它一个问题 | 输入「解释一下当前目录里都有什么」 | AI 结合终端上下文给出回答 |

> 💡 首次打开会有**新手指引气泡**，指向收藏夹、AI 讨论、主题等按钮——点完它们是好事，但真正要"体验价值"，还是上面这 4 步最实在。

## 三、让 AI 真正能干活的开关

Hesi 的终端**不需要任何 Key 就能用**。但 AI 对话需要至少一个 LLM 的 Key：

1. 点界面里的 **设置**（齿轮 / 语言切换附近），找到 AI 提供商配置
2. 填入 `OPENAI_API_KEY` 或 `ANTHROPIC_API_KEY`（也可填本地模型 `LM Studio` 的 base-url）
3. 保存后回到聊天框，直接对话即可

**没填 Key 会怎样？** 终端和浏览器控制照常用；只有 AI 对话会提示"未配置 Key"。这不是故障，是预期降级。

## 四、圆桌讨论：Hesi 的核心玩法

"圆桌"是 Hesi 招牌功能——让 AI 助手和多个 CLI Agent（opencode / codex / claude / aider）就同一任务**多轮讨论**，而非单打独斗。

1. 在聊天面板点「**讨论**」按钮
2. 从已发现的 CLI Agent 中**多选**（最多 4 个）
3. 设定讨论轮次（rounds），把你的任务写清楚
4. 发送，观察 AI 与 Agent 交替发言、逐轮收敛

> 讨论伙伴来自系统 PATH 扫描 + 左侧栏收藏夹。把常用 Agent 加收藏，会在讨论下拉里默认勾选、置顶、带 ★。

## 五、设置你的「工作空间」（重要）

新终端默认出生在用户主目录（`C:\Users\<你>`），但你可能想在**项目目录**里干活。

- 终端标签栏 / 聊天工具栏有醒目的 **📂 选择工作空间 ∨** 按钮
- 点它 → 选目录 → 新开的终端会自动 `cd` 过去，AI 执行命令的默认目录也同步切换
- 选择会记住（localStorage），下次启动不用重选

> ⚠️ 如果不设，终端和 AI 用的默认目录**不一致**（终端在用户主目录、AI 在 Hesi 启动目录），容易"AI 跑错地方"。设一次工作空间能避免这个坑。

## 六、常用快捷键

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+K` | 命令面板（搜 CLI / 操作） |
| `Ctrl+Shift+F` | 终端内搜索 |
| `Ctrl+=` / `Ctrl+-` | 终端字号放大/缩小 |
| `Ctrl+Shift+R` | 浏览器强刷（清前端缓存） |
