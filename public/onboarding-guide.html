🧠 Hesi 是什么？

「合思」= 让多个 AI 在一起思考

Hesi（合思）是一个运行在浏览器里的通用终端中枢平台。它把终端、AI 助手、浏览器自动化、插件生态整合到一个网页标签页中——打开浏览器就是全部工具。

🖥️多会话终端
🤖AI 智能体圆桌
🌐浏览器控制
🔌MCP + 插件市场

💡 名字由来：「合」代表协作与融合，「思」代表思考与智能。Hesi 的核心理念是让多个 AI 协作讨论，而非单打独斗。

02 / 07
⚡ 为什么选择 Hesi？
⚡ 痛点：终端窗口 + AI 聊天 + 浏览器 + 编辑器 = 几十个标签页来回切，每次切换都在浪费时间。

Hesi 的核心优势：

🎯一个标签页搞定所有
🔒本地优先 · 数据不出本机
🧩离线可用 · U盘即用
📖MIT 开源 · 完全可控

✅ 零安装依赖：自带便携 Node.js 运行时，双击即跑。

✅ 默认仅监听本地回环（127.0.0.1），绝不暴露到局域网。

💡 适合人群：开发者、运维工程师、AI 工程师、数据科学家 —— 所有需要同时操作终端和 AI 的人。
03 / 07
🛠️ 核心功能一览

🖥️ 多会话终端

基于 xterm.js + WebGL 渲染，每个标签独立 PTY 进程。会话持久化到 IndexedDB，关闭浏览器回来终端还在。自动检测文件路径/URL 可点击预览。内置 CLI 发现引擎扫描 PATH 一键启动。

🌐 浏览器控制中心

通过 CDP 协议集成 Chrome/Edge：导航页面、截图、点击元素、填表单、执行 JS、抓取网络请求。内置浏览器农场支持多隔离会话并行。

🔌 MCP 服务 + 插件系统

模块化 MCP 服务器 + 内置 Session Manager + 安全策略引擎 + 审计日志。Bearer Token 鉴权 + 令牌桶限流。插件市场一键安装、热重载。

04 / 07
🚀 如何使用？三步上手
1

选择语言环境

从左侧预设选择 Node、Python、Go 等运行环境，或自定义 CLI 配置。

2

安装依赖

使用 npm/pnpm/pip 安装项目依赖。欢迎页可一键安装预置 AI Agent（如 OpenCode）。

3

开始对话

在对话框输入问题，发送图片/视频/文件给 AI。开启「AI 讨论」让多智能体协作解答。

✨ 小技巧：对话框支持 📎 发送附件（图片 AI 能看懂、视频 Claude 能分析）；按 Enter 发送，Shift+Enter 换行。
⚡ Windows 用户：双击 tray.bat 启动；macOS/Linux：运行 ./tray.sh。然后打开 http://127.0.0.1:4264 即可。
05 / 07
⭐ AI 讨论 — 核心亮点

多智能体圆桌辩论，比你单聊 AI 强十倍

开启「AI 讨论」后，你的指令不再只由一个 AI 回答。AI 助手作为协调者，召集你选择的 CLI Agent（OpenCode、Codex、Aider、Claude 等）进行多回合协作讨论——互相质疑、补充、完善方案。整个过程实时可见，最终给你经过多方论证的结论。

🧑‍💼AI 助手 = 协调者 + 裁判
🤖CLI Agent = 专业执行者
⚡后台静默执行（无 TUI 噪音）
🔄增量裁剪 + 循环检测防失控
🌟 这是 Hesi 与其他所有 AI 工具最大的区别 —— 不是「AI 替你干活」，而是「一群 AI 一起帮你思考」。适合架构设计、代码审查、故障排查等需要多角度分析的复杂场景。
06 / 07
📎 多模态对话

Hesi 不只是文字聊天 —— 你可以直接发送多种类型的内容给 AI：

🖼️图片 — AI 真正「看懂」
🎬视频 — Claude 分析内容
📄代码文件 — 直接读取
📊数据文件 — CSV/JSON/日志

📎 点击对话框的附件按钮（或直接拖拽文件），选择要发送的内容。AI 会收到完整信息并基于内容回答问题。支持格式：jpg/png/gif/webp/mp4/webm/pdf/txt/md/json/csv/py/js/ts... 等 30+ 种。

💡 典型用法：截图报错让 AI 排查、发架构图让 AI review、丢日志文件让 AI 分析异常。

🔒 安全设计原则

✅ 本地优先：默认仅监听 127.0.0.1，改 0.0.0.0 会触发高危警告
✅ 环境变量过滤：自动脱敏 API_KEY / TOKEN / PASSWORD
✅ 双层限流：全局 API + WebSocket 消息节流
✅ 命令策略：内置危险命令黑名单，支持黑白名单模式
✅ 审计日志：所有操作可追溯
